# Product Explorer

Product Explorer is a small, browser-based product catalog. It loads products from the [Fake Store API](https://fakestoreapi.com/products), displays them as cards, and lets you search product titles, categories, and descriptions or sort by price.

## Features

- Browse product images, names, categories, and prices.
- Search products by title, category, or description.
- Sort products from high to low or low to high by price.
- See loading, empty-search, and request-error messages.

## Setup

No package installation or build step is required.

1. Clone or download this repository.
2. Open `index.html` in a modern web browser.
3. Make sure you have an internet connection so the app can retrieve product data from the Fake Store API.
